## 🍗 المشروع المميز: مساعد "بازوكا" الذكي (AI Restaurant Bot)
هذا المشروع ليس مجرد بوت عادي، بل هو نظام خدمة عملاء متكامل لمطعم "بازوكا" يعتمد على تقنية الـ **RAG** (Retrieval-Augmented Generation).

### 📸 استعراض حي (Live Preview)
![Bazooka AI Assistant](image_2026-03-10_235447339.jpg)
*واجهة الموقع الرسمية مع دمج الشات بوت الذكي المتناسق مع الهوية البصرية (اللون البرتقالي).*

### ✨ أهم المميزات:
- **نظام RAG احترافي:** البوت يقرأ المعلومات من قاعدة بيانات معرفية (PDF) مخزنة في **Supabase Vector Store** للرد بدقة على الأسعار ومواعيد العمل.
- **تخصيص العملة والموقع:** يدعم الرد بالريال السعودي (SAR) ويقدم تفاصيل الفروع بدقة.
- **ذكاء اصطناعي تفاعلي:** قدرة عالية على فهم أسئلة العملاء حول قائمة الطعام (مثل: "عندكم تشيكن برجر؟") والرد بشكل فوري.
- **تكامل n8n:** إدارة كاملة لتدفق البيانات بين الموقع، قاعدة البيانات، وموديلات الذكاء الاصطناعي.

### 📁 محتويات المستودع:
- `rag_for_restaurant.json`: ملف الـ Workflow الكامل الخاص بـ n8n (جاهز للاستيراد).
- `assets/`: صور توضيحية لواجهة البوت والـ Workflow.

### 🛠️ التقنيات المستخدمة:
- **Automation:** n8n 
- **AI Models:** Gemini / OpenAI
- **Vector Database:** Supabase (Postgres)
- **UI:** Custom Web Chat Widget

## 🚀 كيف تشغل الـ Workflow؟
1. قم بتحميل ملف `rag_for_restaurant.json`.
2. ارفعه في سيرفر الـ **n8n** الخاص بك.
3. اضبط الـ Credentials الخاصة بـ Supabase و AI Model.
4. ابدأ في استقبال طلبات "القرمشة"!
